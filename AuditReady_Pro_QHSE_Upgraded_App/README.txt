HOW TO RUN
1. Extract this ZIP folder.
2. Open CMD inside the extracted folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run auditready_pro_qhse_app.py

FEATURES INCLUDED
- Dark brown oval login design
- CAPA tracker
- Automatic CAPA for Minor NC, Major NC and Observation
- PDF report generation with photo evidence
- Excel export
- Digital signatures for auditor and auditee / branch manager
- Photo upload and annotation note section
- Branch trend dashboard
- Repeated non-conformity tracker
- Dashboard filters: branch, auditor, date, criterion, NC type, overdue CAPA
- Admin user management: add users, deactivate users, reset passwords, assign branches
- Role restrictions: QHSE submit audits, Branch Managers view assigned branch only, Admin sees all
- Audit scheduling and missed audit display
- Email and WhatsApp sharing links
- Starbites branding: logo upload, document number, issue date, version number

NOTE
Email and WhatsApp sharing opens the email/WhatsApp app. Attach the downloaded PDF manually unless you later connect a mail server.
Photo annotation is included as an annotation note field. Drawing directly on images can be added later with a custom component.
